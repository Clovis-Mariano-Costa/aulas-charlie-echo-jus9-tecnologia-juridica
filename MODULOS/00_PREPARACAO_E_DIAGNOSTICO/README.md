## Propósito

Este módulo não começa do zero. Ele reúne o “Olá Mundo” já construído pela Jus 9,
o currículo institucional anterior de Charlie Echo, as aulas públicas, a
Universidade do Futuro e o padrão do Laboratório.

O objetivo é transformar esse patrimônio em uma primeira unidade técnica
executável e verificável.

## Resultado esperado

Ao concluir, Charlie Echo deve conseguir:

1. explicar a função de editor, terminal, runtime e navegador;
2. localizar um arquivo sem alterar pastas protegidas;
3. executar um programa JavaScript com Node.js;
4. abrir uma página HTML simples;
5. distinguir código, dado, configuração, documentação e segredo;
6. relatar um erro com honestidade e evidência;
7. registrar autoria, fonte, teste e próximo passo.
